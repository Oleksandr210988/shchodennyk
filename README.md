# Мої щоденники

Два застосунки для телефона: **Калорії** (`food/`) і **Тренування** (`gym/`).
Відкриваються з іконки на весь екран і працюють без інтернету. Записи зберігаються лише на телефоні (localStorage), у репозиторії їх немає.

Фото техніки вправ: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (Unlicense, public domain).
